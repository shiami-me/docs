# Roadmap

## V1 — Current Release

**DeFi → DeFAI**\
**Status:** Live ✅

#### Key Features

* **Chatbot Interactions**\
  Swap, lend, borrow, and stake across audited DeFi protocols.

#### Supported Protocols

* **Silo Finance**
* **Aave V3**
* **Beets.fi**
* **Pendle Finance**
* **Native Staking on Sonic** using Origin, Angles, Beets, Beefy
* **Shadow Finance** (work in progress)
* **Euler Finance** (work in progress)

#### Basic Actions

* Token swaps
* Wallet transfers
* Portfolio tracking (basic)

#### Special Offer

**Zero Fees during MVP**\
No platform fees for users interacting during the early-stage MVP.

* **Auto-yield Strategies**\
  Intelligent allocation to the best-performing strategies without user intervention.

  Automatic rebalancing across the highest APY pools periodically.

* Deep performance insights.

* **Privy Wallet Improvements**
