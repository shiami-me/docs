# Aave Sonic Markets

## Aave V3 on Shiami

#### Getting Started with Aave V3 on Shiami

You can interact with the Aave V3 protocol on the Sonic network directly through Shiami using natural language commands. Simply type what you want to achieve in the chat.

#### Exploring Markets and Your Position

**Viewing All Markets**

To see all available Aave V3 markets on Sonic and their current rates:

<pre><code><strong>Show me all Aave V3 markets
</strong></code></pre>

or

```
What are the current supply and borrow rates on Aave?
```

**Exploring Specific Markets**

To get details about a particular asset's market:

```
Tell me more about the USDC.e market on Aave V3
```

or

```
What's the borrow APR for wS on Aave?
```

or

```
Show Aave market details for S
```

**Checking Your Position**

To see your overall Aave V3 financial position (collateral, debt, health factor):

```
Show my Aave V3 position
```

or

```
What's my health factor on Aave?
```

#### Supplying Assets (Depositing)

**Supplying ERC20 Tokens**

To deposit ERC20 tokens like USDC.e, wS, etc.:

```
Deposit 100 USDC.e into Aave
```

or

```
Supply 0.5 wS to Aave V3
```

**Supplying the Native Token (S)**

To deposit the native Sonic network token "S":

```
Deposit 10 S into Aave
```

or

```
Supply 25 native S token to Aave V3
```

#### Withdrawing Supplied Assets

**Withdrawing ERC20 Tokens**

To withdraw previously supplied ERC20 tokens:

```
Withdraw 50 USDC.e from Aave
```

or

```
Withdraw all my wS from Aave V3
```

**Withdrawing the Native Token (S)**

To withdraw previously supplied native "S" tokens (Requires prior approval for the aToken):

```
Withdraw 5 S from Aave
```

or

```
Withdraw my entire supplied S balance from Aave V3
```

#### Borrowing Assets

_(Note: Borrowing currently uses the Variable Interest Rate only)_

**Borrowing ERC20 Tokens**

To borrow ERC20 tokens against your collateral (Requires sufficient collateral and health factor > 1):

```
Borrow 1000 USDC.e from Aave
```

or

```
I want to borrow 0.1 wS from Aave V3
```

_(Note: You cannot borrow the native "S" directly. Borrow the wrapped version, "wS", instead)._

#### Repaying Debt

_(Note: Repaying assumes you are repaying a Variable Interest Rate loan)_

**Repaying ERC20 Debt**

To repay debt using ERC20 tokens:

```
Repay 500 USDC.e debt on Aave
```

or

```
Repay my full wS loan on Aave V3 using wS
```

**Repaying Debt with Native Token (S)**

To repay your wS debt using the native "S" token:

```
Repay 10 S towards my Aave debt
```

or

```
Repay my entire S debt using native S on Aave V3
```
