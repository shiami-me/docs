# Pendle on Shiami

### Getting Started with Pendle on Shiami

You can interact with Pendle in two ways:

1. **Natural language commands** - Simply type what you want to do
2. **Specialized Pendle Dashboard(of course)**

### Exploring Markets and Assets

#### Viewing All Markets

To see all available Pendle markets:

```
Show me all Pendle markets
```

or

```
What are the current APYs on Pendle markets?
```

#### Exploring Specific Markets

To get details about a particular market:

```
Tell me more about the stS Pendle market
```

or

```
What's the liquidity in the Pendle ETH market?
```

#### Finding Available Assets

To see all tokens you can use on Pendle:

```
What tokens can I use on Pendle?
```

or

```
Show me all Pendle PT tokens
```

### Providing Liquidity

#### Adding Single-token Liquidity

Provide liquidity with a single token:

```
Add 100 USDC.e to the stS Pendle market
```

or

```
Provide 5 aUSDC SY as liquidity to Pendle aUSDC market
```

#### Adding Balanced (Dual) Liquidity

Provide liquidity with both a token and PT:

```
Add 100 USDC.e and 50 PT to Pendle market stS
```

or

```
Provide balanced liquidity to Pendle stS market with 10 stS and 5 PT
```

#### Zero Price Impact (ZPI) Liquidity

Add liquidity without affecting the market price:

```
Add liquidity to stS Pendle market with zero price impact using 200 USDC.e
```

### Managing Your Liquidity

#### Removing Liquidity

Withdraw your liquidity position:

```
Withdraw 50 LP tokens from stS Pendle market and get USDC.e
```

or

```
Remove liquidity from Pendle aUSDC market and receive aUSDC
```

#### Withdrawing Balanced Position

Remove liquidity and receive both tokens:

```
Remove 50 LP tokens from Pendle market stS and get both USDC.e and PT
```

### Trading on Pendle

#### Swapping Tokens

Trade between different tokens:

```
Swap 100 USDC.e for PT in the stS Pendle market
```

or

```
Exchange 50 YT for stS in Pendle
```

### Yield Management

#### Converting to Standardized Yield (SY)

Convert base tokens to SY tokens:

```
Mint stS SY tokens from 100 USDC.e
```

or

```
Convert 10 Sonic to aUSDC SY tokens
```

#### Splitting Yield (PT & YT)

Separate yield into Principal and Yield components:

```
Mint PT and YT for stS market using 100 USDC.e
```

#### Redeeming Tokens

Convert SY tokens back to base tokens:

```
Redeem 100 stS SY tokens to USDC.e
```

or recombine PT and YT:

```
Redeem PT+YT from stS market to USDC.e
```
