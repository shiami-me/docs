# SwapX on Shiami

### Exploring Pools

**Viewing V2 Pools**

To see all available v2 pools on SwapX:

```
Get top 5 v2 pools by volume on SwapX
```

or

```
Get v2 pools with token0Symbol as USDC on SwapX
```

You can also filter by liquidity:

```
Get v2 pools with min liquidity on SwapX
```

**Exploring Concentrated Liquidity (V3) Pools**

To get details about concentrated liquidity pools:

```
Get top 5 v3 pools by volume on SwapX
```

or

```
Get v3 pools with token0Symbol as USDC on SwapX
```

or filter by liquidity:

```
Get v3 pools with min liquidity on SwapX
```

#### Token Information

Get details about tokens on SwapX:

```
Get info for S token on SwapX
```

or

```
Get info for token address on SwapX
```

or view top tokens:

```
Get top 5 tokens by volume on SwapX
```

### Providing Liquidity

**Adding Liquidity**

Provide liquidity to pools:

```
Add liquidity to USDC.e/aSonUSDC pool on SwapX
```

or with custom slippage:

```
Add liquidity to USDC.e/aSonUSDC pool on SwapX with 1% slippage
```

Provide liquidity using S tokens:

```
Add liquidity to S/USDC.e pool on SwapX
```

**Creating Concentrated Liquidity Positions**

Create a new concentrated liquidity position:

```
Create a new position on S/USDC.e pool on SwapX
```

or with custom slippage:

```
Create a new position on wS/USDC.e pool on SwapX with 1% slippage
```

**Adding Liquidity and Staking (V2 Pools)**

Add liquidity and automatically stake your LP tokens:

```
Add liquidity to USDC.e/aSonUSDC pool on SwapX and stake
```

or with custom slippage:

```
Add liquidity and stake to USDC.e/aSonUSDC pool on SwapX with 1% slippage
```

or with S token:

```
Add liquidity and stake to S/USDC.e pool on SwapX
```

***

### Managing Your Liquidity

**Removing Liquidity**

Remove liquidity from your positions:

```
Remove 10% LP from USDC.e/aSonUSDC pool on SwapX
```

or with custom slippage:

```
Remove 50% LP from USDC.e/aSonUSDC pool on SwapX with 1% slippage
```

or with wrapped S:

```
Remove 10% LP from wS/SHADOW pool on SwapX with 1% slippage
```

or with S:

```
Remove 10% LP from S/USDC.e pool on SwapX
```

***

### Staking and Rewards

**Checking Your Position**

View your current position in a pool:

```
Get swapxfi position for USDC.e/aSonUSDC pool on SwapX
```

or view all concentrated liquidity positions:

```
Get all v3 positions on SwapX
```

**Staking LP Tokens**

Stake your LP tokens to earn rewards:

```
Stake 10% of LP tokens in USDC.e/aSonUSDC pool on SwapX
```

or

```
Stake all LP tokens in USDC.e/aSonUSDC pool on SwapX
```

You can also use:

```
Deposit all LP tokens in USDC.e/aSonUSDC pool on SwapX
```

**Unstaking LP Tokens**

Withdraw your staked LP tokens:

```
Unstake 10% of LP tokens from USDC.e/aSonUSDC pool on SwapX
```

or

```
Unstake all LP tokens from USDC.e/aSonUSDC pool on SwapX
```

You can also use:

```
Withdraw all LP tokens from USDC.e/aSonUSDC pool on SwapX
```
